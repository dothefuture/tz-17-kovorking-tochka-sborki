## 3. Короткие ссылки (5.3)
ВКонтакте — vk.cc (vk.com/cc), Telegram — clck.ru. Вставить полную ссылку → сократить → записать в `short_url`.
Перейти по короткой ссылке и снять адресную строку со всеми метками → `screens/utm/U-05-short.png` и т. д.

## 4. Отработка ссылок (5.5)
Для каждой строки: открыть публикацию с другого устройства/инкогнито → нажать ссылку → снимок адреса `screens/utm/U-xx.png` →
GA4 Realtime, карточка Session source → снимок. Для U-01, U-05, U-07, U-09, U-10, U-11, U-12 отправить заявку с именем «Тест U-05» и т. п.
Через 24–48 ч: Reports → Acquisition → Traffic acquisition, Session source / medium → `screens/utm/traffic-acquisition.png` (≥ 6 пар).

## 5. ManyChat (раздел 7)
1. manychat.com → Sign up with Instagram → подключить профессиональный аккаунт.
2. Automation → **New automation** → название `IG · Free Day Nov 2026 · Day Reel`.
3. Trigger: **Instagram → User comments on your Post or Reel** → *Specific Post or Reel* → выбрать Reel → Keywords: `ДЕНЬ`.
4. Включить **Reply to comments publicly**, три варианта ответа (случайный выбор):
   - «Отправили приглашение в личные сообщения ☕»
   - «Проверьте директ — тест-день ждёт»
   - «Готово! Приглашение и промокод уже в сообщениях»
5. Instagram → Send message: «Здравствуйте! Это «Точка сборки». Приходите на бесплатный тест-день: что вас ждёт и как записаться — по кнопке ниже.»
   Кнопка **«Хочу приглашение»** → URL = ссылка **U-02**.
6. Вторая ветка: ещё одна автоматизация на тот же Reel, keyword `КОМАНДА`, сообщение «Кабинеты для команд на 4 и 8 человек: фото, цены и
   свободные даты — по кнопке ниже.», кнопка **«Кабинеты»** → ссылка **U-03**.
7. **Set Live**. Проверка со второго аккаунта (пауза ≥ 2 мин между комментариями), снимки каждого шага → `screens/instagram/`.
   Сообщение на тестовом аккаунте может прийти в «Запросы».
