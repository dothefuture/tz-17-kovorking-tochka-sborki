## Подсказки для заполнения

- **User vs Traffic acquisition.** User acquisition считает пользователей по *первому* источнику (First user source),
  Traffic acquisition — сеансы по источнику *каждого* сеанса. Если человек пришёл из Instagram, а потом вернулся напрямую,
  в User acquisition он один раз в instagram, а в Traffic acquisition — два сеанса: instagram и (direct).
- **Открытая vs закрытая воронка.** В открытой пользователь может войти с любого шага, в закрытой — только с первого
  (page_view) и строго по порядку, поэтому на последнем шаге закрытой воронки число не больше, чем в открытой.
- **Заявки vs generate_lead.** Причины расхождения: блокировщики рекламы и трекеров режут gtag, тестовые заявки, отправленные
  напрямую в приёмник (И-05), уход со страницы до отправки события, задержка обработки данных в GA4 (до 24–48 часов).
- **Атрибуция.** Admin → Attribution settings: по умолчанию модель Data-driven (на маленьком объёме данных фактически работает как
  последний непрямой клик), окно для ключевых событий привлечения — 30 дней, для остальных — 90 дней. Сверить со своим ресурсом.
- **Ограничение.** Раздел «Реклама» (пути к ключевым событиям) в России не заполняется: Google Реклама не подключается.
  Цепочку действий перед заявкой показывает исследование «Обратный путь».
- **Заявок на 100 сеансов** = заявки из таблицы / сеансы GA4 × 100 (вкладка «Кампании» DataLens).
