# Таблица заявок и приёмник Apps Script (ТЗ, раздел 6)

1. Google Таблицы → новая таблица **«TochkaSborki — Leads»**.
2. **Расширения → Apps Script** → вставить `apps-script/Code.gs` → сохранить.
3. Выбрать функцию **`setup`** → **Выполнить** → разрешить доступ. Создадутся листы:
   - `leads` — 13 столбцов в порядке ТЗ, выпадающие списки `tariff`, `team_size`, `status`
     (`new, contacted, visit_booked, visited, paid, lost`; другое значение отклоняется), подсветка пустых
     обязательных ячеек (красным) и повторов `request_id` (жёлтым), телефон хранится как текст;
   - `events` — регистрации на мероприятия;
   - `utm` — реестр ссылок, столбец `full_url` собирается формулой `CONCATENATE` из меток
     (вставить строки из `docs/utm.csv`, столбцы A–I и K–N; J заполнится формулой);
   - `ga4_traffic`, `ga4_leads` — для выгрузок GA4 под DataLens.
4. **Развернуть → Новое развёртывание → Веб-приложение**: выполнять от имени **меня**, доступ **все** → скопировать URL `…/exec`.
5. Вставить URL в `js/form.js` (константа `ENDPOINT`) → commit → push → Vercel обновит сайт.
6. **Настройки доступа** таблицы: «Читатель» для e-mail Заказчика.

## Проверки
- Контрольная заявка с сайта → строка в `leads` с метками, `status = new`, `created_at` проставлен (И-03).
- Повтор (И-05): отправить тот же запрос ещё раз, например из консоли браузера
  ```js
  fetch(ENDPOINT, {method: 'POST', body: new URLSearchParams({form_type:'lead', request_id:'REQ-уже-записанный-id', name:'Повтор', phone:'+79000000000', tariff:'flex', team_size:'1'})}).then(r => r.json()).then(console.log)
  ```
  Ответ `{"ok": false, "error": "Заявка с таким request_id уже записана", "duplicate": true}`, новой строки нет.
- Статусы (6.4): одну тестовую заявку провести `new → contacted → visit_booked → visited → paid`, другую — в `lost`.

После правок кода приёмника: **Развернуть → Управление развёртываниями → Изменить → Новая версия** (URL сохранится).
